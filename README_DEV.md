# テーブルコピー拡張機能 - 開発者向けドキュメント

このドキュメントは、テーブルコピー拡張機能の開発者向けの技術情報を提供します。

## プロジェクト構造

```
Ex_table/
├── manifest.json       # 拡張機能のマニフェストファイル
├── background.js       # バックグラウンドサービスワーカー
├── content.js          # コンテンツスクリプト（メイン機能）
├── .gitignore          # Git除外設定
├── README.md           # ユーザー向けドキュメント
└── README_DEV.md       # このファイル（開発者向けドキュメント）
```

## アーキテクチャ

### 1. manifest.json
拡張機能の設定ファイルです。Manifest V3を使用しています。

**主な設定項目:**
- `permissions`: 必要な権限（コンテキストメニュー、アクティブタブ、クリップボード書き込み）
- `host_permissions`: すべてのURLでの動作を許可
- `background.service_worker`: バックグラウンドスクリプトの指定
- `content_scripts`: コンテンツスクリプトの設定

### 2. background.js
バックグラウンドで動作するサービスワーカーです。

**主な機能:**
- コンテキストメニュー（右クリックメニュー）の作成
- メニュークリック時のイベントハンドリング
- コンテンツスクリプトへのメッセージ送信

**処理フロー:**
1. 拡張機能インストール時に右クリックメニューを作成
2. メニューがクリックされたらコンテンツスクリプトにメッセージを送信

### 3. content.js
Webページに注入されるスクリプトです。メイン機能を実装しています。

**主な機能:**
- 右クリックされた要素の追跡
- テーブルの検出と抽出
- 結合セルの処理
- TSV形式への変換
- クリップボードへのコピー
- 通知の表示

**処理フロー:**
1. `contextmenu`イベントで右クリックされた要素を記録
2. バックグラウンドからメッセージを受信
3. 最も近いテーブル要素を検出
4. テーブルをマトリックスに変換（結合セルを処理）
5. TSV形式に変換
6. クリップボードにコピー
7. 通知を表示

## 主要な関数の説明

### findClosestTable(element)
指定された要素から最も近いテーブル要素を見つけます。

**動作:**
- 要素自身がテーブルの場合はそれを返す
- そうでない場合は親要素を辿ってテーブルを探す

### convertTableToTSV(table)
テーブル要素をTSV形式の文字列に変換します。

**処理:**
1. 2次元配列（マトリックス）を作成
2. 各セルのrowspanとcolspanを考慮してマトリックスに配置
3. マトリックスをTSV形式の文字列に変換

**結合セルの処理:**
- `rowspan`と`colspan`属性を読み取り
- 結合されたセルの範囲に同じテキストを配置
- 既に埋まっているセルはスキップ

### getCellText(cell)
セルからテキストを抽出します。

**特徴:**
- ネストされたテーブルのテキストは除外
- すべてのテキストノードを収集
- 空白文字をトリミング

### copyToClipboard(text)
テキストをクリップボードにコピーします。

**方法:**
1. **Clipboard API**（推奨）: `navigator.clipboard.writeText()`
2. **execCommand**（フォールバック）: `document.execCommand('copy')`

### showNotification(message, isSuccess)
画面右上に通知を表示します。

**特徴:**
- 成功時は緑色、失敗時は赤色
- フェードイン・フェードアウトアニメーション
- 3秒後に自動的に消える

## 開発環境のセットアップ

### 必要なもの
- Google Chrome または Microsoft Edge（最新版）
- テキストエディタ（VS Code推奨）
- Git（バージョン管理）

### デバッグ方法

1. **拡張機能のリロード**
   - `chrome://extensions/` にアクセス
   - 「更新」ボタンをクリック

2. **バックグラウンドスクリプトのデバッグ**
   - `chrome://extensions/` で「サービスワーカー」をクリック
   - DevToolsが開きます

3. **コンテンツスクリプトのデバッグ**
   - テストページで右クリック → 検証
   - Consoleタブでエラーや`console.log`出力を確認

4. **ブレークポイントの設定**
   - DevToolsのSourcesタブでファイルを開く
   - 行番号をクリックしてブレークポイントを設定

## テスト

### 手動テスト項目

1. **基本機能**
   - [ ] テーブル上で右クリックメニューが表示される
   - [ ] 「テーブルをコピーする」メニューが動作する
   - [ ] コピーした内容がExcelに正しく貼り付けられる

2. **結合セル**
   - [ ] rowspanのあるテーブルが正しくコピーされる
   - [ ] colspanのあるテーブルが正しくコピーされる
   - [ ] rowspanとcolspanが混在するテーブルが正しくコピーされる

3. **ネストされたテーブル**
   - [ ] 内側のテーブルのみがコピーされる
   - [ ] 外側のテーブルがコピーされる場合、内側のテーブルのテキストが除外される

4. **エッジケース**
   - [ ] 空のテーブルでエラーが発生しない
   - [ ] 空のセルが正しく処理される
   - [ ] 複雑なHTMLを含むセルが正しく処理される

## パフォーマンス最適化

### 実装済みの最適化
1. **イベントリスナーの効率化**: `contextmenu`イベントをキャプチャフェーズで処理
2. **DOM操作の最小化**: 必要な範囲のみを走査
3. **メモリ管理**: 通知要素を適切に削除

### 今後の改善案
1. 大きなテーブルの処理を最適化（Web Workerの利用など）
2. キャッシュの活用

## セキュリティ考慮事項

1. **XSS対策**: `textContent`を使用してテキストのみを抽出
2. **権限の最小化**: 必要最小限の権限のみを要求
3. **コンテンツセキュリティポリシー**: Manifest V3の要件に準拠

## ビルドとパッケージング

### 開発版のインストール
上記の「インストール方法」を参照してください。

### 配布用パッケージの作成

1. **Chrome Web Storeへの公開**
   ```bash
   # ZIPファイルを作成
   zip -r extension.zip . -x "*.git*" -x ".vs/*" -x "README_DEV.md"
   ```

2. **プライベート配布**
   - `chrome://extensions/`で「パッケージ化」をクリック
   - .crxファイルと.pemファイルが生成されます

### プロモーション画像の生成

Chrome Web Store用のプロモーション画像を自動生成できます。

**必要なパッケージ:**
```bash
pip install selenium pillow
```

**使用方法:**
```bash
python create_promo_images.py
```

このスクリプトは以下の3つのプロモーション画像を生成します：
- `promo_images/small_promo_tile_440x280.png` - Small Promo Tile
- `promo_images/large_promo_tile_920x680.png` - Large Promo Tile
- `promo_images/marquee_promo_tile_1400x560.png` - Marquee Promo Tile

**手動での作成:**
1. `promo_image_template.html` をブラウザで開く
2. 各プロモーション画像の上で右クリック → スクリーンショットを撮影
3. 画像編集ソフトで指定サイズにトリミング

## コーディング規約

1. **JavaScript**
   - ES6+の機能を使用
   - strict modeを有効化
   - コメントは日本語で記述

2. **命名規則**
   - 関数: キャメルケース（例: `findClosestTable`）
   - 定数: UPPER_SNAKE_CASE（例: `MAX_SIZE`）
   - プライベート変数: 先頭にアンダースコア（例: `_privateVar`）

3. **コメント**
   - 関数の説明はJSDoc形式
   - 複雑なロジックには必ずコメントを追加

## トラブルシューティング

### よくある問題

1. **拡張機能が動作しない**
   - Manifest V3の権限設定を確認
   - サービスワーカーのエラーを確認

2. **クリップボードにコピーできない**
   - HTTPSページでテスト
   - ブラウザのクリップボード権限を確認

3. **テーブルが正しく認識されない**
   - 要素がTABLEタグであることを確認
   - CSSでスタイリングされた疑似テーブルには対応していない
