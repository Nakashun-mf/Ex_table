📸 プロモーション画像の作成方法

このページを使用して、Chrome Web Store用のプロモーション画像を作成できます。

  1. 各画像の上で右クリック → 「名前を付けて画像を保存」（またはスクリーンショットツールを使用）
  2. 画像編集ソフト（Photoshop、GIMP、Canvaなど）でカスタマイズ（任意）
  3. 指定のサイズで保存（PNG形式推奨）
  4. Chrome Web Store Developer Dashboardにアップロード

注意： アイコンの絵文字（📋）は実際のアイコン画像（icon128.png）に置き換えることをお勧めします。
