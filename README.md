# テーブルコピー拡張機能

Webページ上のテーブルを右クリックメニューから簡単にコピーできるChrome拡張機能です。結合セル（rowspan/colspan）にも対応しており、Excelに貼り付け可能な形式でクリップボードにコピーします。

## 機能

- **右クリックメニューからコピー**: テーブル上で右クリックすると「テーブルをコピーする」メニューが表示されます
- **結合セル対応**: rowspanやcolspanで結合されたセルも適切に処理します
- **Excel対応**: TSV形式（タブ区切り）でコピーするため、Excelやスプレッドシートに直接貼り付け可能です
- **ネストされたテーブル対応**: テーブル内に別のテーブルがある場合、右クリックした内側のテーブルのみをコピーします
- **すべてのWebページで動作**: あらゆるWebサイトのテーブルに対応しています
- **視覚的なフィードバック**: コピー成功時に通知が表示されます

## インストール方法

### 開発者モードでのインストール

#### Chrome

1. このリポジトリをダウンロードまたはクローンします
2. Chromeブラウザを開き、`chrome://extensions/` にアクセスします
3. 右上の「デベロッパーモード」を有効にします
4. 「パッケージ化されていない拡張機能を読み込む」をクリックします
5. このプロジェクトのフォルダを選択します
6. 拡張機能がインストールされます

#### Microsoft Edge

1. Edgeブラウザを開き、`edge://extensions/` にアクセスします
2. 左下の「開発者モード」を有効にします
3. 「展開して読み込み」をクリックします
4. このプロジェクトのフォルダを選択します

## 使い方

1. テーブルが表示されているWebページを開きます
2. コピーしたいテーブル上で右クリックします
3. コンテキストメニューから「テーブルをコピーする」を選択します
4. テーブルの内容がクリップボードにコピーされます
5. ExcelやGoogleスプレッドシートなどに貼り付け（Ctrl+V / Cmd+V）できます

## 技術仕様

- **Manifest Version**: 3
- **言語**: JavaScript (ES6+)
- **フォーマット**: TSV（タブ区切り値）
- **クリップボード**: Clipboard API（フォールバック: execCommand）

## 注意事項

- テーブル内のテキストのみがコピーされます（リンクのURLや画像は含まれません）
- ネストされたテーブルがある場合、右クリックした内側のテーブルのみがコピーされます
- 一部の動的に生成されるテーブルでは、正しく動作しない場合があります
- クリップボードAPIの制限により、HTTPS環境での動作を推奨します

## トラブルシューティング

### コピーができない場合

1. ブラウザのコンソール（F12）でエラーメッセージを確認してください
2. ページをリロードしてから再度試してください
3. 拡張機能を一度無効にして、再度有効にしてください

### テーブルが正しくコピーされない場合

- 複雑な構造のテーブルの場合、一部のセルが正しく処理されない可能性があります
- CSSで視覚的に表現されているテーブル（`<div>`要素など）には対応していません
